# М2 - Бильярд на гладком столе

## О проекте

Моделирует упругое столкновение двух гладких бильярдных шаров в горизонтальной плоскости. При ударе шары деформируются по закону Гука. Движение рассчитываем численно по второму закону Ньютона

Рассматриваются лобовые и не лобовые ( косые??) удары, шары одинаковой и разной массы, а также столкновение двух движущихся шаров. Результаты сравниваются с законами сохранения энергии и импульса и формулами упругого удара
